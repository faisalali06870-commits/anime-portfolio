## 🌟 Key Features

- **300-Frame Image Canvas Sequence**: High-performance 60 FPS scrubbing animation pinned dynamically across the hero and about sections.
- **Dynamic Character Avatar Switcher**: 1-click toggle between the 300-frame 3D sequence and custom Faisal Anime illustration with 8-direction cursor eye-tracking!
- **3D Orbital Projects Showcase**: Floating 3D orbital trajectory with 6 interactive project cards featuring 3D tilt, video loops, and modal inspect windows.
- **Cyber Overdrive Mode ⚡**: Native Web Audio API audio synthesizer with glowing neon overdrive visuals and ambient audio effects.
- **Direct WhatsApp & Email Integration**: Functional contact form routing inquiries seamlessly to WhatsApp and Email.
- **Dark / Light Theme Toggle**: Seamless aesthetic modes with calibrated contrast ratios and custom glassmorphism cards.
- **Responsive & Touch-Ready**: Optimized for desktop, tablet, and mobile viewing with swipe gestures and magnetic cursor.

---

## 🛠️ Tech Stack

- **Frontend Core**: Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Smooth Scrolling**: Locomotive Scroll v4
- **Animation Engine**: GSAP (GreenSock) & ScrollTrigger
- **Audio Engine**: Native Web Audio API Synthesizer
- **Visuals & 3D**: HTML5 2D Canvas + 3D CSS Transforms

## 🚀 Quick Start / Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/faisalali06870-commits/anime-portfolio.git
   cd anime-portfolio
   ```

2. **Run locally:**
   - Open `index.html` with [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code, or:
   ```bash
   npx serve .
   ```
   - Visit `http://localhost:3000` or `http://localhost:5500`.
